## What Is Done

### Project Baseline

### Registry Bootstrap Fixes

- Fixed the startup crash caused by block and item ids not being assigned before registration.
- `HLBlockInit` now uses NeoForge's block-aware deferred registration path.
- `HLItemInit` now uses NeoForge's item-aware deferred registration path.
- Block items are registered through deferred item helpers instead of manually during `RegisterEvent`.
- The creative tab now receives item entries instead of raw block entries.

Relevant files:

- `src/main/java/com/vincenthuto/hutoslib/common/registry/HLBlockInit.java`
- `src/main/java/com/vincenthuto/hutoslib/common/registry/HLItemInit.java`
- `src/main/java/com/vincenthuto/hutoslib/HutosLib.java`

### Networking Bootstrap Fixes

- Fixed duplicate payload registration for `hutoslib:packet_spawn_lightning`.
- `HLPacketHandler` now registers payloads through the explicit mod event bus listener only.
- `packet_spawn_lightning` is registered as clientbound instead of bidirectional.

Relevant file:

- `src/main/java/com/vincenthuto/hutoslib/common/network/HLPacketHandler.java`

### `@OnlyIn` Warning Cleanup

- Removed the unused client-only `Vector3.vertex(Matrix4f, VertexConsumer)` method.

Relevant file:

## Important Temporary Compromises

### Build Exclusions

`build.gradle` currently excludes several unported systems so the common/core slice can compile while the 26.1 migration proceeds:

- `com/vincenthuto/hutoslib/client/**`
- `com/vincenthuto/hutoslib/ClientProxy.java`
- `com/vincenthuto/hutoslib/common/registry/HutosLibModelLayersInit.java`
- `com/vincenthuto/hutoslib/common/registry/HLParticleInit.java`
- datagen providers
- `com/vincenthuto/hutoslib/common/recipe/**`
- reload/listener shadow classes
- `ReloadListenerPacket.java`

Do not forget these exclusions exist. They mean the mod is loading with several systems temporarily disabled, not fully ported.

### Arm Banner Rendering

Arm banners currently display as placeholder/generated item models. The old custom item renderer path has not been ported to the 26.1 client item/render-state pipeline.

### Guide Book Rendering

The guide book inventory icon is a placeholder. The actual guide book GUI/model/rendering stack still needs a proper 26.1 client port.

### Custom Recipes

The custom arm banner recipe was removed from resources because the serializer is excluded from compilation. Restore it only after the recipe package and serializer registration are ported.

### Generated Resources

Some generated resources were manually rewritten to match 26.1 format. Once datagen is restored, regenerate them from updated providers and check that generated output stays stable.
