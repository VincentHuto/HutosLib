# HutosLib NeoForge 1.21.1 → 1.21.11 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port HutosLib from NeoForge 21.1.x (MC 1.21.1) to NeoForge 21.11.x (MC 1.21.11) with all breaking API changes resolved and the mod compiling cleanly.

**Architecture:** This is a mechanical migration — no new features, no refactors beyond what the API changes require. Tasks are ordered so each one leaves the project in a compilable (or clearly-in-progress) state. The `ResourceLocation → Identifier` rename is done first because 51 files depend on it and every other task touches those files too.

**Tech Stack:** Java 21, NeoForge 21.11.x, Gradle (MDG plugin 2.0.141+), IntelliJ IDEA

**Background:** In 1.21.4, `ParticleRenderType` became a record with constructor `new ParticleRenderType(String name, RenderType renderType)`.   ```java

  public static final RenderType PARTICLE_GLOW = RenderType.create(
      "hutoslib:particle_glow",
      DefaultVertexFormat.PARTICLE,
      VertexFormat.Mode.QUADS,
      256,
      RenderType.CompositeState.builder()
          .setShaderState(PARTICLE_SHADER)
          .setTextureState(new RenderStateShard.TextureStateShard(
              TextureAtlas.LOCATION_PARTICLES, false, false))
          .setTransparencyState(LIGHTNING_TRANSPARENCY)
          .setLightmapState(LIGHTMAP)
          .createCompositeState(true)
