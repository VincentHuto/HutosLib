# HutosLib Effect Templates

Paste these JSON files into the matching template item screen:

- `lightning/*.json` goes in a Lightning Template item.
- `tendrils/*.json` goes in a Tendril Template item.

You can then right-click a matching tester block with the template to copy the setup onto the block, or hold the template in your offhand while using the tester item to spawn that exact preset.

Tendril templates can set `"blendColors": false` for sharper outer/core separation. In that mode the outer sheath renders first and the inner core redraws last, which helps high-contrast looks like black and gold avoid a muddy blended core.
